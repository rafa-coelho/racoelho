## Sobre a vaga

Vaga remota via Truelogic (staff augmentation nearshore) para atuar diretamente com um cliente dos EUA: uma empresa global de insights e estratégia que ajuda grandes marcas a tomar decisões orientadas por dados nos setores de entretenimento, mídia, tecnologia, games, esportes e cultura. Você vai liderar o DevOps que sustenta as plataformas de dados e software do cliente.

## O que você vai fazer

- Projetar, implementar e manter a infraestrutura cloud no Google Cloud Platform usando Terraform e boas práticas de Infrastructure as Code.
- Gerenciar ambientes Kubernetes (GKE), garantindo escalabilidade, confiabilidade e uso eficiente de recursos.
- Construir e manter pipelines de CI/CD com GitHub Actions e Jenkins.
- Monitorar a saúde da infraestrutura com observability, logging, alertas e melhorias em resposta a incidentes.
- Colaborar com os times de Data Engineering, dando suporte a plataformas de analytics e pipelines de dados em Snowflake, dbt, Dagster e BigQuery.
- Manter e modernizar infraestrutura híbrida, incluindo Windows Server, Oracle, SQL Server e ambientes legados em AWS.
- Aprimorar a gestão de identidade e acesso com soluções modernas como Workload Identity e OIDC.
- Detectar e resolver drift de infraestrutura, mantendo os ambientes seguros, reprodutíveis e com custo otimizado.
- Atuar em parceria com times internos e fornecedores externos de infraestrutura, e mentorar engenheiros disseminando boas práticas de DevOps e automação.

## Requisitos

- 6+ anos de experiência em DevOps, Cloud Infrastructure, SRE ou Platform Engineering.
- Forte experiência prática com Google Cloud Platform (GCP). Experiência com AWS ou Azure também é válida, desde que haja disposição para se aprofundar em GCP.
- Experiência avançada com Terraform e Infrastructure as Code, incluindo state management e drift detection.
- Experiência em produção gerenciando Kubernetes (GKE preferencialmente).
- Experiência construindo e mantendo pipelines de CI/CD com GitHub Actions, Jenkins ou ferramentas similares.
- Bom domínio de cloud networking, IAM, segurança e automação de infraestrutura.
- Experiência dando suporte a ambientes híbridos (cloud moderna + plataformas legadas de Windows e bancos de dados).
- Familiaridade com plataformas de dados como Snowflake, dbt, Dagster ou BigQuery.
- Scripting com Python ou Bash.
- Boa capacidade de troubleshooting, comunicação e colaboração entre times.
- Inglês avançado (comunicação será constante com o cliente dos EUA).

## Diferenciais

- Administração de Oracle, SQL Server ou Windows Server.
- Auth0, OIDC ou outras soluções modernas de gestão de identidade.
- Conhecimento de FinOps ou práticas de otimização de custos em cloud.
- Suporte a infraestrutura de analytics ou plataformas de dados em larga escala.
- Experiência mentorando engenheiros ou liderando iniciativas de DevOps.
