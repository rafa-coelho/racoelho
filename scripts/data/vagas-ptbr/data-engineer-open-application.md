## Sobre a vaga

Candidatura aberta para Data Engineer no modelo staff augmentation nearshore, por meio de uma consultoria sediada em Nova York. Você trabalha de forma 100% remota, alocado em projetos de empresas dos EUA (de startups a Fortune 500), com pagamento em USD.

## O que você vai fazer

- Escrever código em Python para soluções de processamento de dados, usando bibliotecas como Pandas e PySpark.
- Consumir dados de diferentes fontes, como REST APIs.
- Trabalhar com data stores relacionais e não relacionais (HBase, Cassandra ou MongoDB; S3, blobs), incluindo consumo e design.
- Lidar com data streams (Kafka, Kinesis, Flume) e filas de mensagens (SQS, SNS, RabbitMQ, etc).
- Garantir que o modelo de dados escale e entregue alta performance, incluindo data stores distribuídos.
- Construir data pipelines e pipelines de ingestão e streaming escaláveis, com processamento de dados/streams (Spark, Flink, Hadoop).
- Fazer ETL com ferramentas como Talend, Informatica e SQL Server Integration Services (SSIS).
- Implementar soluções de data warehouse (Snowflake, Redshift, Hive), disponibilizando dados quase em tempo real para diversos sistemas clientes.
- Projetar e implementar aplicações e serviços de dados em nuvem pública (AWS, GCP ou Azure) usando plataformas PaaS.

## Requisitos

- 5+ anos de experiência profissional na função.
- Sólido domínio de Python aplicado a processamento de dados (Pandas, PySpark).
- Experiência com data stores relacionais e não relacionais, streams e filas de mensagens.
- Experiência com data warehouses e SQL para construção de armazenamento de dados.
- Experiência com nuvem pública (AWS, GCP ou Azure) e plataformas PaaS.
- Familiaridade com regulações de privacidade de dados e boas práticas.

## Diferenciais

- Ferramentas de BI e visualização de dados (Looker, Power BI, Tableau) — design, implementação e evolução.
- Arquiteturas de processamento de dados como Lambda Architecture.
- Indexação (Solr ou ElasticSearch).
- Experiência convertendo Jupyter Notebooks em processos de produção.
- Ferramentas de orquestração de pipelines e workflows, como Airflow.
- Data lakes.
