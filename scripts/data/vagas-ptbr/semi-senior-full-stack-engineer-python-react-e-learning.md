## Sobre a vaga

Vaga remota para atuar via modelo nearshore (staff augmentation) com uma empresa dos EUA, um provedor premiado de soluções SaaS inteligentes. Você vai trabalhar de forma remota a partir da América Latina, integrando o time do cliente americano.

## O que você vai fazer

- Projetar, desenvolver e manter aplicações web e microsserviços robustos e escaláveis usando Python e React.
- Construir APIs RESTful limpas e eficientes e integrar serviços de backend complexos.
- Apoiar deploys containerizados e trabalhar com pipelines de CI/CD em infraestrutura cloud (principalmente AWS).
- Usar ferramentas modernas de desenvolvimento com IA para otimizar fluxos de trabalho e incorporar recursos de IA generativa e integrações de modelos quando aplicável.
- Participar de sprint planning, code reviews e discussões de design de software, mantendo alto padrão de qualidade e arquitetura.

## Requisitos

- 3+ anos de experiência em desenvolvimento de software, com proficiência prática forte em Python e React.
- Experiência comprovada em projetar e construir REST APIs escaláveis e arquiteturas de microsserviços.
- Bom domínio de plataformas cloud (preferência por AWS), práticas de CI/CD e deploys containerizados (ex.: Docker).
- Experiência anterior com aplicações de GenAI/LLM, prompt engineering e integração de LLMs/modelos.

## O que oferecem

- Trabalho 100% remoto, de onde você preferir.
- Remuneração competitiva em USD, acima da média de mercado.
- Paid Time Off (férias/folgas remuneradas).
- Autonomia para gerenciar seu tempo, com foco em resultados.
- Projetos de alto impacto com empresas americanas líderes de mercado.
