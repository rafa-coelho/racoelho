## Sobre a vaga

Vaga remota via Truelogic (modelo nearshore/staff augmentation) para atuar como Principal Full-Stack Engineer junto a um cliente dos EUA que desenvolve soluções SaaS em nuvem para instituições públicas. Você vai construir do zero uma nova aplicação SaaS, atuando como líder técnico hands-on num time com forte uso de desenvolvimento assistido por IA (abordagem AI-first, shift-left total e sem QA dedicado).

## O que você vai fazer

- Projetar, desenvolver e entregar aplicações SaaS escaláveis usando .NET, Angular, SQL Server/PostgreSQL e AWS.
- Ser dono da entrega ponta a ponta das features — do modelagem de domínio e serviços de backend até frontend, testes automatizados, deploy e suporte em produção.
- Gerar código pronto para produção com ferramentas de desenvolvimento assistido por IA, a partir de designs do Replit, seguindo padrões internos de design, componentes reutilizáveis, acessibilidade, design responsivo e boas práticas de frontend.
- Colaborar com Architects para definir a arquitetura da aplicação e validar abordagens técnicas construindo PoCs quando fizer sentido.
- Desenhar soluções com padrões arquiteturais modernos: Domain-Driven Design (DDD), CQRS, Event-Driven Architecture, Backend-for-Frontend (BFF) e API Gateway.
- Construir aplicações Angular modernas com standalone components, Signals, RxJS, Reactive Forms e arquitetura de componentes reutilizáveis.
- Modelar dados de forma eficiente, otimizar performance de SQL e implementar padrões escaláveis de integração e mensageria.
- Mentorar engenheiros por meio de orientação técnica, discussões de arquitetura, code reviews e compartilhamento de conhecimento.
- Usar ferramentas de desenvolvimento com IA como GitHub Copilot, Cursor, Claude Code e workflows de IA agêntica para melhorar qualidade e produtividade.

## Requisitos

- Mais de 10 anos de experiência profissional em engenharia de software.
- Experiência em papel de liderança técnica (Principal, Lead Engineer ou equivalente).
- Domínio avançado de C#, .NET, Entity Framework, SQL Server/PostgreSQL e Angular.
- Sólida experiência com DDD, CQRS, REST APIs, event-driven architecture e sistemas distribuídos.
- Experiência projetando aplicações SaaS seguras, escaláveis e multi-tenant.
- Forte conhecimento em otimização de SQL, modelagem de dados e tecnologias como Redis e OpenSearch/Elasticsearch.
- Experiência com testes automatizados, CI/CD, Git, desenvolvimento Agile e práticas modernas de DevOps.
- Experiência com ferramentas de observabilidade e monitoramento, além de análise estática como SonarQube e Mend.
- Experiência com assistentes de código por IA como GitHub Copilot, Cursor, Claude Code ou similares.

- PTO (férias/folgas remuneradas).
- Autonomia para gerenciar seu tempo, com foco em resultados.
