## Sobre a vaga

Vaga remota no modelo staff augmentation nearshore para atuar com um cliente dos EUA: uma agência digital que entrega soluções web escaláveis e de alta qualidade para grandes organizações, com forte foco em CMS e plataformas de experiência digital. Você atua como Senior Fullstack Engineer em múltiplos projetos client-facing, construindo aplicações escaláveis com .NET e frameworks front-end modernos.

## O que você vai fazer

- Projetar, desenvolver e manter features fullstack em vários projetos de clientes.
- Construir serviços de backend escaláveis com C# e .NET Core.
- Desenvolver front-ends responsivos e de fácil manutenção com JavaScript e React (ou Angular).
- Integrar plataformas de CMS, APIs e serviços de terceiros para experiências digitais orientadas a conteúdo.
- Participar de discussões de arquitetura e contribuir com decisões técnicas.
- Conduzir e participar de code reviews para manter o padrão de qualidade.
- Colaborar de perto com designers, estrategistas, producers e outros engenheiros ao longo do ciclo de desenvolvimento.
- Garantir qualidade via testes, otimização de performance e boas práticas.
- Trabalhar de forma independente, comunicando progresso, riscos e bloqueios de forma proativa.

## Requisitos

- 5+ anos de experiência como desenvolvedor.
- Sólida experiência com C# e .NET Core.
- Forte experiência de front-end com JavaScript e React (Angular também é aceito).
- Bons fundamentos de HTML, CSS e JavaScript.
- Experiência construindo e consumindo REST APIs.
- Experiência prática com Umbraco CMS, incluindo Umbraco 13 ou versão mais recente.
- Experiência com Microsoft SQL Server.
- Experiência com Git e workflows de CI/CD.
- Autonomia para trabalhar com supervisão mínima e gerenciar prioridades.
- Inglês avançado, escrito e falado.

## Diferenciais
