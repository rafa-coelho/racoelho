## Sobre a vaga

Vaga remota no modelo staff augmentation nearshore, por meio de uma consultoria sediada em Nova York, para atuar em um cliente americano: uma consultoria global de insights e estratégia que atua na interseção entre conteúdo, cultura e tecnologia. Você vai construir interfaces de alta qualidade para produtos orientados a dados (data-driven), com forte equilíbrio entre execução técnica, fluência em dados e sensibilidade de design.

## O que você vai fazer

- Construir e manter interfaces baseadas em componentes usando React (hooks, componentes funcionais).
- Implementar a lógica de frontend com abordagem TypeScript-first, incluindo tipagem estrita para respostas de API e dados transformados.
- Transformar, normalizar e preparar dados de backend e analytics para consumo no frontend.
- Gerenciar o estado da aplicação com Redux, decidindo quando usar estado global vs. local.
- Lidar com dados incompletos, edge cases e schemas em evolução sem quebrar os fluxos da UI.
- Implementar UIs pixel-perfect e prontas para produção a partir de mockups ou requisitos escritos.
- Colaborar com os times de design, produto e backend para esclarecer requisitos e resolver ambiguidades cedo.
- Trabalhar a partir de tickets no Azure DevOps, seguindo os critérios de aceite com precisão.
- Escrever funções utilitárias limpas e testáveis e componentes reutilizáveis.
- Seguir os padrões do projeto (estrutura de pastas, padrões de estado, estilização, linting).
- Participar de code reviews, dando e recebendo feedback construtivo.
- Ser dono das features de ponta a ponta, da implementação ao QA e correção de bugs.

## Requisitos

- Experiência avançada com React usando hooks, componentes funcionais e padrões modernos.
- Experiência avançada com TypeScript, definindo interfaces e tipos para APIs e modelos de dados do frontend.
- Sólida experiência com Redux ou bibliotecas similares de gerenciamento de estado.
- Capacidade comprovada de trabalhar com UIs complexas, data-driven, e lógica de renderização dinâmica.
- Conforto para transformar dados de backend ou tracking em estruturas amigáveis ao frontend.
- Bom entendimento dos detalhes de implementação de UI (espaçamento, hierarquia, estados de interação).
- Autonomia para trabalhar de forma independente uma vez que os requisitos estejam definidos.
- Comunicação clara e proativa, com iniciativa para tirar dúvidas quando os requisitos não estão claros.
- Experiência com fluxos colaborativos baseados em tickets (ex.: Azure DevOps, Jira).
- Forte foco em qualidade de código, manutenibilidade e consistência.

- 100% remoto, de onde você trabalha melhor.
- Remuneração competitiva em USD, acima da média de mercado.
- PTO (férias/folgas remuneradas).
- Autonomia para gerenciar seu tempo com foco em resultados.
- Projetos de alto impacto com empresas americanas líderes de mercado, junto a um time sênior e multicultural na América Latina.
