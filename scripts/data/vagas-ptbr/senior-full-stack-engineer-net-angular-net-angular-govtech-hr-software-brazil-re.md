## Sobre a vaga

Vaga remota (modelo nearshore) via Truelogic para atuar diretamente com uma empresa dos EUA que desenvolve soluções cloud de GovTech/RH para o setor público. Você vai construir e manter aplicações SaaS escaláveis, seguras e de alta performance usando o stack Microsoft.

## O que você vai fazer

- Projetar, desenvolver e manter microsserviços escaláveis e resilientes no ecossistema .NET
- Construir e evoluir aplicações web full-stack seguras e performáticas com C#, Angular e SQL Server
- Modelar e otimizar schemas de banco, stored procedures e queries SQL complexas visando performance e escalabilidade
- Escrever código limpo, documentado e testado (testes unitários e de integração)
- Usar ferramentas de desenvolvimento assistidas por IA para ganhar produtividade e qualidade
- Investigar e resolver problemas complexos em desenvolvimento, testes e produção
- Aplicar boas práticas de arquitetura, multi-threading, estruturas de dados e design N-Tier
- Colaborar em times ágeis (sprint planning, reviews, retros) e gerenciar código com Git e pipelines de CI/CD

## Requisitos

- 5+ anos de experiência com C#, .NET, Angular e SQL
- Forte experiência com MS SQL Server: stored procedures, indexação, otimização de queries e modelagem relacional
- Experiência construindo aplicações SaaS corporativas escaláveis
- Familiaridade com AWS ou outras plataformas de cloud
- Experiência com ferramentas de desenvolvimento assistidas por IA (GitHub Copilot, Claude Code, Cursor ou similares)
- Entendimento de conceitos de IA: LLMs, MCP e RAG (Retrieval-Augmented Generation)
- Bom domínio de HTML, CSS, arquitetura de software, multi-threading e otimização de performance
- Experiência com testes unitários/integração e ambientes Shift Left
- Inglês fluente (escrito e falado)
- Graduação em Computação, Engenharia, TI ou área correlata, ou experiência prática equivalente

## Diferenciais

- Conhecimento de GraphQL e práticas modernas de desenvolvimento de APIs
